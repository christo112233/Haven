# 多语言（中文 / English）

Haven 的中英文文案集中在 `locales/<locale>/*.json`，**Python 后端和前端共用同一份词表**：
后端用 `i18n.tr()`，前端用 `t()`（`web/i18n.js`，词表由 `server.py` 注入 `index.html`）。
语言是设备本地偏好，存在 `haven-settings.json` 的 `language` 字段（`system` / `zh-CN` / `en-US`），
不随共享图库同步。`system` 跟随系统语言，不支持的系统语言回退英文。

```
locales/
  zh-CN/
    common.json    # 服务端/主程序基础文案 + 共享错误
    menu.json      # macOS 原生菜单
    backend.json   # api / metadata_store / platform_support / updater 等后端文案
    web.json       # 前端界面文案
  en-US/
    ...同名文件
```

片段文件按文件名顺序合并，key 不得在不同片段中重复。新增文案时**两种语言必须同时添加**。

## key 命名

- 扁平点分 key，小写短横线：`web.settings.title`、`backend.error.not-folder`
- 前端：`web.` 前缀；后端：`backend.` 前缀；原生菜单：`menu.`；服务端内部：`server.`；通用：`error.` / `main.`
- 占位符用 `{name}`，中英文占位符必须完全一致
- 英文单数形式用 `key.one`（基础条目 = 复数/通用形式）；中文不写 `.one`
  ```json
  "web.status.items": "{count} items",
  "web.status.items.one": "{count} item"
  ```
  调用 `t("web.status.items", {count: n})` / `i18n.tr("web.status.items", count=n)`
- 不允许空字符串、不允许值为 key 本身

## 前端用法

静态标记：

```html
<span data-i18n="web.settings.title">设置</span>
<button data-i18n-title="web.toolbar.refresh" title="重新扫描">…</button>
<input data-i18n-placeholder="web.search.placeholder" placeholder="搜索文件名">
<button data-i18n-aria-label="web.toolbar.refresh" aria-label="重新扫描">…</button>
```

页面加载完成后调用一次 `applyI18n()`。动态文案用 `t()`：

```js
status.textContent = t("web.status.items", { count: n });
```

数字和日期按当前语言格式化：`new Intl.NumberFormat(i18nLocale())`、
`toLocaleDateString(i18nLocale(), …)`。

不翻译的数据：用户标签、相册名、文件名/文件夹名、排序与筛选的存储值（`name` / `date` /
`favorite` / `>=` 等）、颜色 key、文件扩展名、`RAW` / `HEIC` / `ISO` 等技术缩写、
`Rejected` 产品术语（中英文都保留英文）。

## 后端用法

```python
import i18n

raise ValueError(i18n.tr("backend.error.folder-missing"))
job["warnings"].append(i18n.tr("backend.warning.cache-readonly", path=str(parent)))
```

异常文案在抛出时按当前语言生成即可（`Api.set_language()` 会更新全局语言并触发前端重载）。
后台线程已生成的历史 warning 不回溯翻译。

## 切换语言

`Api.set_language(value)` 保存偏好 → `i18n.configure()` → 重建 macOS 原生菜单 →
前端 `location.reload()`。服务端重新渲染 `index.html` 时注入新词表，因此切换后没有旧语言残留。
注意：pywebview 的系统文件选择框跟随 **系统语言**，不跟随应用语言，这是平台限制。

## 检查

```bash
python -m unittest tests.test_i18n -v
```

测试会校验：中英 key 集合一致、占位符一致、无空值、`locales/` 可被正确注入。
